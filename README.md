# Celebrare — Photo Gallery

A responsive photo gallery built with **React, Vite, and Tailwind CSS** as part of the Celebrare Frontend Internship assignment.

### Features
- Fetches 30 photos from the Picsum Photos API
- Responsive photo grid
- Real-time search by author name
- Favourites with `useReducer` and `localStorage` persistence
- Custom `useFetchPhotos` hook
- Loading and error states
- Optimized filtering with `useCallback` and `useMemo`

### Tech Stack
React · Vite · Tailwind CSS · JavaScript · Picsum Photos API

### Live Demo

git clone <your-repository-url>
